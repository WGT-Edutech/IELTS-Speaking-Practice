# IELTS Speaking Practice

B2 IELTS Speaking practice portal: cover-flow deck gallery with 12 theme-reactive single-file decks (Technology, Environment, Education, Health, Work, Culture, Globalization, Media, Science, City, Food, Shopping). Each deck: 6 Part 1 questions, 1 Part 2 cue card, 4 Part 3 discussion questions, vocabulary with 8-language tooltips, timer, specular buttons, 7 color themes.
